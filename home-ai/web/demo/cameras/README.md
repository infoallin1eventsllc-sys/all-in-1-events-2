# Sample camera pictures (demo only)

The browser-only demo has no cameras, so it shows these four stills, each
labelled "Sample picture" on every screen. They are frames from Meridian's
film of the model home (`film/clips/D-welcome-alt.mp4` and
`film/clips/C-becomes-real.mp4`), scaled to 768x432. A real home never
shows them: its panels show its own Home Assistant cameras, or say that none
are connected.
