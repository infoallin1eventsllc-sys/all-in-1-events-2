# "Inferno Dreams speaks": TikTok / Reels promo (9:16, 25s)

The candle speaks about itself in the first person, using its own voice. Every shot is built from the client's **real product photos**, used as supplied. Effects are layered on top of the photos and never alter them.

- **Edit, preview or export (free, in the browser):** https://www.clipkit.dev/public-editor?id=a990ef49-7bbb-425c-bea2-a289dfc0f463
- **Voice:** ElevenLabs, "Sara – Smooth Ads" (eleven_multilingual_v2). The file is `inferno-dreams-voiceover.mp3` (23.7s).
- **Source:** `inferno-dreams-clipkit.json`, generated by `build_clipkit_source.py`. Note that a frosted caption band was then added in the editor, so the live editor project is the authoritative version.
