# Finished renders — the masters

Every finished piece from the Sep 6–7 motion work, at full quality, kept here
because these are **irreplaceable**. They were rendered in a sandbox whose disk
does not survive a container restart, and the raw recordings they were cut from
went with it. Re-cutting them from scratch is not a small job.

These are masters, not web assets. Nothing serves them from here. The
web-sized copies live in the website repo at `public/video/` — 720p, faststart,
roughly a quarter the size — and those are what the site and the media library
point at.
