# Meta ad test 1: Hook A vs Hook B ($70, 7 days)

Status: READY, NOT LIVE. Nothing runs until Otis approves the videos and the text below
and presses Publish himself in Meta Ads Manager. Nothing is posted to the Facebook page.

## What is being tested
One ad, two versions. Everything after the first 3 seconds is identical.
- Hook A: the original opening. The presenter says "Every business I meet has the same
  problem." under the Meridian logo board.
- Hook B: same footage and sound, but a bold card covers the logo board for the first
  3 seconds: "Your customers are searching right now / Are they finding you?"

Source: the page's top reel (54 views, posted 7 Nov 2026, 37 s), the presenter ad.
Files (each 37 s, H.264 + AAC, 30 fps): Meridian-Ad_Hook-A_* and Meridian-Ad_Hook-B_* in
4x5 (1080x1350, feed), 9x16 (1080x1920, Reels/Stories, content clear of the app buttons),
1x1 (1080x1080) and 16x9 (1920x1080, plain side panels, no blur).

## Ad text (for approval; the same for both ads so only the hook differs)
Primary text:
  Your customers are already searching. Are they finding you?
  Meridian Interface builds the website, the online store, the booking system, the CRM
  and the video ads, all from one Houston studio.
Headline: Book a design appointment
Description: Websites, apps and video ads
Call to action button: Book Now
Website URL, Hook A:
  https://meridianinterface.com/?utm_source=facebook&utm_medium=paid_social&utm_campaign=test1&utm_content=hook-a
Website URL, Hook B:
  https://meridianinterface.com/?utm_source=facebook&utm_medium=paid_social&utm_campaign=test1&utm_content=hook-b
(The site records utm_source as the lead's channel, so a booking from either ad lands in
the CRM as a "facebook" lead, and utm_content says which hook brought it.)

## Settings
- Campaign objective: Traffic. Performance goal: Landing page views.
- Budget: ad set budget, $5.00 a day per ad set, 2 ad sets (one per hook), 7 days.
  Total cap $70. Same audience and placements in both ad sets.
- Audience: Houston, TX + 25 miles (covers Katy); ages 25 to 65; no detailed targeting
  on the first run (let Meta find people; same in both ad sets so only the hook differs).
- Placements: Advantage+ placements, with the 4x5 file for feeds and 9x16 for
  Stories and Reels (Ads Manager lets you pick a file per placement).
- Special ad category: none.

## Click-by-click (about 10 minutes)
1. Go to adsmanager.facebook.com, pick the Meridian Interface ad account, add a card
   under Billing if asked.
2. Click + Create. Choose Traffic. Name the campaign "Meridian test 1 hooks".
   Leave Advantage campaign budget OFF (so each hook gets its own $5 a day).
3. Ad set: name "Hook A". Conversion location: Website. Performance goal: Landing page
   views. Budget: Daily, $5. Schedule: start date, end 7 days later.
   Audience: Location Houston, Texas + 25 mi. Age 25 to 65. Placements: Advantage+.
4. Ad: name "Hook A". Identity: Meridian Interface page (and Instagram if linked).
   Format: Single image or video. Media: upload Meridian-Ad_Hook-A_4x5.mp4, then set
   the Stories and Reels placement to Meridian-Ad_Hook-A_9x16.mp4.
   Paste the primary text, headline and description above. Call to action: Book Now.
   Website URL: the Hook A link above.
5. Duplicate the ad set (three dots > Duplicate), rename it "Hook B", and in its ad
   swap the two videos for the Hook B files and the URL for the Hook B link.
   Change nothing else.
6. Review, then Publish. Meta reviews ads, usually within a day.

## What to read after 7 days (Ads Manager > Columns > Video engagement)
- Hook rate = 3-second video plays / impressions. The winner is the higher one.
- Hold rate = ThruPlays / 3-second plays.
- CTR (link click-through rate), CPC (cost per link click), landing page views.
- Leads: new contacts in the CRM with source "facebook" (utm_content says which hook).
