How this page was made

Rendered, not generated.

01

Model the set at true scale

One unit is one metre. Sofas, truss, drape and fixtures built as primitives at the dimensions on the set sheet above. Nothing eyeballed.

02

Light it like the event

Spot cones from floor level for the uplights, emissive tops and point lights for the LED tables, one soft key. Brand hexes only.

03

Render the camera move to frames

An 80° arc that rises and closes in. Forty-eight stills, headless, deterministic. The same forty-eight every time.

04

Scrub them on scroll

Scroll position picks the frame and draws it to a canvas. It looks like video and obeys the wheel, which is why it feels directed.

05

Grade, grain and vignette in CSS

The warm cast, the corner falloff and the 28% noise over this whole page are four rules of stylesheet, not a render pass.

Frames preload on idle and none is drawn before it has decoded. Device pixel ratio is capped at 2. On reduced motion or Save-Data the sequence never starts and the page shows a single still.

Honest about what this is. A blocking render, not photoreal: procedural geometry, no textures, no fabric simulation. It is accurate on layout, scale and lighting design, which is what a client needs to approve a set. Photoreal is a longer job and a different budget.
